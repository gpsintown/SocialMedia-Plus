# Import and review measured outcomes

Read the current settings and private sources/reports. IMPORT accepts a user-supplied local export; inspect `python3 scripts/smp import --help` and the selected importer help before use. Supported formats vary by importer. Preserve original files privately, source/observation dates and deduplication evidence. Never upload private history to make analysis easier or import sample people into a live database.

A profile/connection export describes that export's coverage. It does not prove current activity, a complete follower roster, or a comment sent by this app. Use the follower import only for an actual observed roster and its completeness metadata; never infer an unfollow from an incomplete snapshot. Review relationship bucket assignments against documented roles/context, not names or protected traits.

For REVIEW, resolve the selected week, or the last complete week, in the user's timezone. Use `weekly-review` with its documented options and read current content/action/metric/interaction records. Refresh through permitted visible UI, a scoped connector or a supplied export when available. Record a metric using `metric add` only with its observed value, source, time and window. Missing values use explicit unavailable status, never zero. Different windows and definitions must not be silently compared.

Review reach and useful conversation outcomes alongside the user's workload and writing feedback. Separate observed changes from causal claims; a small personal account sample rarely establishes why a post performed differently. Keep raw account analytics private. Identify one concrete experiment with hypothesis, variable, time window and decision criterion using the experiment ledger.

Save a private report with evidence freshness, coverage limits, worthwhile themes, actual user edits and the next test. WEEK can reuse a recent report and complete the batch without a duplicate review. If data is sparse, say what can be learned now and what remains unknown rather than inventing a score.
