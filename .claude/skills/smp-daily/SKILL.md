# Daily LinkedIn conversations

Follow [daily](../../../workflows/daily.md). Read the current invocation and exact scope, relationship coverage/history, cooldowns and source evidence. A current explicit live ENGAGE/NETWORK/DISCOVER/RECRUITERS/REPLIES command permits contextual comments/replies during that session. Preview sends nothing. Record actual authorization evidence; installation and examples provide none.

Use observed professional relevance and current parent-thread context. Prefer useful continuing conversations and include observed incoming followers where relevant. Stable profile IDs retain overlapping membership/history. Check an existing response before writing another one. Skip when the contribution would be generic or the context cannot be established.

Use a compact facts/context/voice pass. Prepare exact response/context in local files, run the action preflight, submit once through an available authorized route and save a confirmed receipt or uncertainty. A click is not a receipt. Stop at the deadline or user stop, preserve results and reconcile before retrying.

For ENGAGE+ or RECRUITER+, additionally load the corresponding plus workflow and private policy. Normal commands do not include private messages, invitations, follows, applications or bulk engagement. Do not claim attention or causation from a profile visit.


## Shared context and host

Before strategy, public writing, language edits, replies or review, read the private `profile/context.md`, `profile/voice.md`, `profile/editorial-policy.md` and relevant `profile/claims.json` records. Never treat templates as personal evidence. Use the user's selected Codex or Claude host model and exposed tools. The local CLI stores records; it is not a remote publisher or LLM. Current user instructions determine authorization, and no previous user's permission is included.
