# Complete weekly preparation

Follow [weekly](../../../workflows/weekly.md). Resolve the Monday date explicitly, inspect existing content/slots and reuse the requested week. Use recent performance and relationship evidence without inventing missing data. Select briefs before writing: intended reader, concrete point, evidence, supported personal angle, format and asset.

Use `content-strategy` and `social` for selection, `linkedin-content` for writing, `smp-council` for substantial critique and Humanizer for final prose. Produce final inspectable assets, not promises. Register immutable content/assets/route/slots with the CLI and run `plan-week --start` for the chosen date.

Return one finished batch linking actual IDs/versions, exact text/assets, destination, route and dated timezone-aware slots. Keep incomplete items and material evidence gaps explicit. WEEK sends nothing. REWORK preserves prior versions; ASSET handles a focused asset change. Scheduling requires the separate instruction for the completed unchanged batch.


## Shared context and host

Before strategy, public writing, language edits, replies or review, read the private `profile/context.md`, `profile/voice.md`, `profile/editorial-policy.md` and relevant `profile/claims.json` records. Never treat templates as personal evidence. Use the user's selected Codex or Claude host model and exposed tools. The local CLI stores records; it is not a remote publisher or LLM. Current user instructions determine authorization, and no previous user's permission is included.
