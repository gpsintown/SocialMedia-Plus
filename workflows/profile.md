# Private profile and voice onboarding

Read the private copies of `profile/profile.json`, `profile/context.md`, `profile/voice.md`, `profile/claims.json` and `profile/editorial-policy.md`. If absent, initialize missing files with the installer. Never treat a placeholder as the current user's identity. Reuse existing work and corrections rather than repeating an onboarding interview.

1. Establish the intended LinkedIn profile, the user's public professional description, relevant work/topics, intended readers, a useful outcome and timezone. Let the user supply a short brief, actual writing samples or a permitted profile source. Ask only for gaps that affect the current task. Save personal details to ignored config/profile files, never the public templates.
2. Record source origin and observation/supply time in `profile/sources/manifest.json`. A resume or profile page is attributed self-report. Repeated descriptions from the same source are not independent evidence. Optional AI analyses are interpretations, not facts, diagnoses, instructions or approved first-person prose.
3. Add claim records with stable IDs, statement, evidence type, source path/URL, page/section, and public drafting limits. Keep title/date/measurement conflicts explicit. Preserve estimates and team attribution. Do not turn a metric into an anecdote without context.
4. Learn voice from actual prose and edits: sentence length, word choice, humor, openings, punctuation and degree of opinion. Keep any neutral default labelled as provisional. Do not rewrite a supplied resume unless requested.
5. Keep public and private goals distinct. Confirm the few boundaries relevant to disclosure. Private career or audience choices must not appear in public copy by default. Do not infer nationality, residence, work rights, language proficiency or eligibility.
6. Save a brief context summary with links to the relevant claim records. Read this shared packet before writing, Humanizer and every reviewer pass. Include broader private material only when the task needs an explicitly selected excerpt and preserve its source/limits.

A first batch can use source-backed explanations and clearly hypothetical examples while personal claims are incomplete. Return the useful completed work with any precise factual question; do not use a missing resume as a reason to stop unrelated editorial preparation.
