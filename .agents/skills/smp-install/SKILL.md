# Install Social Media Plus

Read `AGENTS.md`, the master guide, README host setup instructions and [the installation workflow](../../../workflows/install.md). Resolve the user's chosen clone folder. Read `scripts/smp-install.py --help` and run it with that root and the selected `codex` or `claude` host. Copy only missing public defaults into ignored local configuration/profile files. Preserve existing records and settings. Then run `scripts/smp-start.py` with the same root and inspect the actual dashboard/startup result.

`SMP INSTALL` requests local setup and a supported host listener. Use the current host's real scheduling capability if exposed; otherwise complete the local runtime and leave an honest manual queue fallback. Generated MCP snippets and listener prompts are configuration proposals until loaded/registered in that host. Merge only the needed registration block and retain unrelated settings. Do not start another model provider, fake background execution or claim a browser/session capability based on an installed file.

Verify with one harmless STATUS request picked up in the configured session, save its actual run evidence, and mark listener readiness only after that result. Setup and verification do not authorize social posting, engagement, private outreach or credit use. Keep all credentials, personal configuration and observed identifiers in ignored local files.

A resume is optional for ordinary content work. Begin private profile/voice onboarding only as needed, without populating sample users or contacts. Return the actual dashboard address, setup state and any concrete host/account step still pending.
