# Private profile templates

`SMP INSTALL` copies missing files from this directory into the ignored `profile/` directory. It never imports the original author's profile, resume or history. Edit the private copies, keeping these distributable templates blank.

A resume is optional for content work. If the user supplies one, preserve the unchanged file under `profile/sources/`, record its origin/hash, and derive attributed claim records with limits. For optional recruiter outreach, configure its private path/hash only after review. Do not add example people to the live relationship database.
