Its capabilities depend on the installed product and account. If a picker does not expose a skill, read the `SKILL.md` directly. A role file does not itself prove the host can spawn an agent. Follow `workflows/install.md` to complete only setup supported in the current host. Read `workflows/dashboard-queue.md` for queue processing and manual fallback.
