# Evidence-led analysis

Follow [analysis](../../../workflows/analyze.md) or [eight-week review](../../../workflows/eight-week.md). Inspect importer/report help for actual supported formats and arguments. Preserve original supplied files privately, provenance, observation times and duplicates. Never put test contacts or posts in live records.

Refresh measured outcomes only through permitted sources. Missing metrics are unavailable, not zero. Keep window/definition differences visible and distinguish imported historical events from this app's confirmed external receipts. A connection export is not a complete follower roster.

Combine supported performance observations with user writing feedback, useful conversations and sustainable workload. Explain uncertainty before attributing outcomes. Record one useful experiment with hypothesis, variable, evidence window and decision. Save the private report for WEEK to reuse. An expansion proposal does not activate another platform.


## Shared context and host

Before strategy, public writing, language edits, replies or review, read the private `profile/context.md`, `profile/voice.md`, `profile/editorial-policy.md` and relevant `profile/claims.json` records. Never treat templates as personal evidence. Use the user's selected Codex or Claude host model and exposed tools. The local CLI stores records; it is not a remote publisher or LLM. Current user instructions determine authorization, and no previous user's permission is included.
